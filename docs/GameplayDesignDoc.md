## 一、版本定位与核心变更

《魂火》是一个「状态管理」的肉鸽。核心不是「攒资源→花资源」，而是「在燃烧和枯竭之间反复横跳」。一个资源（魂火）同时承担资源、状态、续航三重身份；6 个标签横向贯穿所有系统；四层循环让短决策有长后果。每一次花费都不只是资产减少，而是身份改变——从燃烧态跌到正常态，战力结构当场变化。

v5.0 相对 v4.7 的核心变更：
1. 魂火不再战后 1:1 转魂，改为跨节点继承；魂的获取变纯粹，依靠战斗掉落、评级奖励、高收益节点、派遣等。
2. 彻底删除武器独立升级与相关旧字段；武器数值全面内联单位。
3. 属性面板固定 6 项，移除感应（ARC）面板；ARC 仅作为内部次级字段保留。
4. 英灵殿 UI 合并复活与转职入口；地图圣坛节点直接调用英灵殿。
5. 战损机制加入"装备自动回收"：阵亡单位的普通防具自动进入待领取区；熔铸防具除外。
6. AI 行为大修：我方 AI 优先踩血瓶、主动治疗/急救/魂火爆发；敌方 AI 不绕路占点、能攻击必贴脸，加入绝望冲锋。
7. 防具连通组加入直观 UI 反馈：悬停高亮同组槽位，显示"已链接 X 件防具（跨 Y 个单位）"。
8. 枯竭不再放大受伤；归零无战斗惩罚；击杀不再额外发魂火。

保留自 v4.7 的有效骨架：状态管理、6 标签、四层循环、七组张力、FORGE 决策爆发、遗物/光环/派遣/竞技场/剧情/编辑器、死眠之钥、遗物精炼、祭祀场横屏探索、高收益节点、Boss 双形态等。

## 二、核心体验

《魂火》的核心体验是：玩家每一场战斗都在管理"魂火状态"，而不是单纯管理血条。燃烧时敢冲，枯竭时收着打，归零时想办法补回。魂火花掉会改变身份；留存会改变下个节点的开局战力。标签决定 Build 轴；转职是押注；商店、问号、掉落、派遣都围绕标签权重转动。四层循环让玩家始终在更长时间尺度下思考：这一刀要不要回魂火？这一件装备要不要熔铸？这一把钥匙要不要跨局攒？

v5.0 的所有机制都围绕三个问题：它是否让魂火状态更有意义？是否让标签选择更重？是否让决策更有痛感？

## 三、三大核心抽象

### 3.1 魂火：一个数值，三重身份

| 身份 | 表现形式 | 玩家心理 |
|---|---|---|
| 资源 | 技能/加点/光环/破盾消耗 | 「花不花？」 |
| 状态 | 燃烧/正常/枯竭/归零 | 「我现在是什么？」 |
| 续航 | 战后数值 100% 保留至下个节点 | 「留不留？」 |

**四状态**

| 状态 | 触发 | 效果 |
|---|---|---|
| 燃烧 | > 50% 上限 | 移速 +1，攻击溅射 50% |
| 正常 | 20%–50% | 无 |
| 枯竭 | < 20% | 暴击伤害 +50% |
| 归零 | =0 | 无战斗惩罚 |

枯竭不再放大受伤；归零不再扣血。压力来自主动技能不可用、燃烧态失效、破盾成本、魂火爆发消耗不可回收。

**携带上限**：`[8,12,16,22,30,40,50]`（Lv0-Lv6），升级费用 `[0,30,80,180,350,600,1000]`。  
**上限叠加**：基础 + 火焰共鸣 + 永恒薪火 +5 / 余烬套装 +3（两者取 max，不叠加）+ 守火者亲密度 ≥10（+1）。  
**初始魂火**：`[0,1,2,3]`，升级费用 `[0,50,200,800]`；守火者亲密度 ≥15 时 +1。

**获得口径（v5.0）**
- 命中 +1：每次结算命中，包含主伤害、双次、法术连击、追击、反击、溅射、AOE，均按 `on_hit(1)` 结算。
- 击杀不再额外发放魂火；`on_kill` 只保留给装备/光环/交叉套装的击杀奖励钩子。
- 我方单位阵亡 +5（软补偿）。
- 装备词条/光环/交叉套装：按原逻辑触发击杀回魂火。
- 战斗奖励发放的是"魂"，不是魂火：START 2 魂 / NORMAL 3 魂 / ELITE 6 魂 / BOSS 15 魂 + 5 额外魂（EconomyManager）。
- 熔合产物"不灭余烬"：归零时回合开始 +1。

**魂火爆发**：拖拽到敌人时，若魂火 ≥3，菜单多一项"魂火爆发"。消耗全部当前魂火，本次攻击强制暴击，并附带 `攻击×15%×魂火数 + 3×魂火数` 额外伤害。爆发后本单位强制结束行动。

**持久层/战斗层分离**
- 战斗层实时变化；进战斗时从持久层同步到战斗层。
- 战斗胜利结算后，剩余魂火 100% 覆盖写回持久层，跨战斗继承。
- 战斗失败/放弃/中途退出：持久层保持战斗前值。
- `settle()` 不再把魂火兑换成魂，仅清空当前魂火，用于周期结束/放弃回营地等场景。

### 3.2 标签：Build 的通货

6 个标签：烈焰 / 轮回 / 灰烬 / 守护 / 献祭 / 余烬。一个标签就是一条轴。玩家的 Build 不是"我选剑士还是法师"，而是"我走守护轴还是烈焰轴"。转职是押注：押对方向，商店源源不断供货。

| 系统 | 标签用法 |
|---|---|
| 单位 | 每个单位带 1-2 个标签 |
| 转职 | 二选一决定单位获得哪个新标签 |
| 装备 | 每件防具带 1 个标签 |
| 套装 | 单位内 2 件同标签生效（基础）；2 件中含 epic+ → 质变强化（v5.1） |
| 交叉套装 | 两条标签各 2 件 → 额外效果（全队级辅助，不抢单位 Build） |
| 熔合 | 2 件同标签紫装 → 对应橙装 |
| 商店 | 前 80% 商品位偏向队内 top-2 标签 |
| 光环 | 每个光环对应 1 个标签 |
| 词条 | 部分词条带标签限制（含穿透词条） |
| 派遣 | 路线有标签，匹配单位 +1 魂 |
| 问号节点 | 标签权重影响事件类型概率 |
| 胜利条件 | 不同标签在占领/夺旗/突进中有战术偏向 |
| 问号保底 | 守护/献祭 → 偏向宝箱；轮回/余烬 → 偏向铁匠铺 |
| 熔铸防具 | 产出时无标签（melt_ 前缀，纯数值/机制特殊防具） |

### 3.3 魂：延迟满足的容器

魂是唯一跨局成长资源。魂火不再战后变现后，魂的获取更纯粹：战斗掉落、评级奖励、高收益节点、派遣、宝箱等。魂只能用于局外升级，全部是永久提升。

魂的消耗口覆盖五个维度：死眠之钥（200 魂）、标签定向器（100 魂）/遗物精炼（150 魂）、Boss 情报（40 魂）、魂火阈值调节器（120 魂）。不新增货币。

死眠之钥是唯一凌驾日常循环的局外干预手段：每局只能携带 1 把，无法通过局内正常战斗/事件掉落获得；`keys` 每局清零，`keys_bought` 跨局累计作为埋点。

## 四、四层循环

### 4.1 微循环（单场战斗）

接敌 → 攻击命中回魂火 → 状态切换 → 战术调整。一场战斗可能发生 2-3 次状态切换。燃烧时敢冲，枯竭时收着打，归零时想办法补回。胜利目标（全灭/占领/夺旗/突进）会重塑微循环；高收益节点让"要不要赌"多一层判断。

**战损管理**：战斗内单位阵亡后永久处于阵亡状态，直到圣坛/BOSS 战后复活。存活单位战斗结算自动回满 HP。阵亡单位的普通防具自动回收进"待领取区"，防止装备永久黑洞；熔铸防具除外，必须复活取回。

**操作交互**：拖拽有就绪主动技能的单位到敌人身上时，弹出菜单询问"普通攻击"还是"释放技能"。玩家自主决定是否消耗魂火。魂火爆发选项不显示额外图标。玩家修女 HP 未满时拖到自己脚下自愈；满血时无效移动不消耗行动；自愈跳过技能菜单。

**AI 交互**：我方 AI 优先去踩回血瓶（血量不满且可达时优先级高于技能加血）；会主动使用群体治疗、急救、魂火爆发（保守规则：Boss 需 ≥5 魂火、强敌需 ≥6 魂火，能普攻击杀则不爆发）。敌方 AI 有绝望冲锋：孤军 vs ≥3 敌，或残血 <40% 且 ≥2 敌时，放弃逃跑直接冲最近敌人。

### 4.2 中循环（一天）

START → NORMAL×2-3 → [CHAPEL | TREASURE | ?] → ELITE×2 → FORGE → BOSS。FORGE 是决策爆发点：买防具、买光环、重 roll 方向、合成、熔合、熔铸、重铸、刷新/升级商店。FORGE 低语每次进触发 1 条，跨局不重复，给情报/flag/解锁，不打断购买。

问号节点在预设类型中随机，受队伍标签权重影响。问号保底：每层至少一个非战斗结果；按 layer 分组，若无显式非战斗且所有 QUESTION 掷出的都是战斗类型，强制改写其中一个为 TREASURE（70%）或 FORGE（30%）；选择受队伍标签影响。

高收益节点是节奏调节器：Day1 ELITE 常配波次 2 + 奖励 ×1.5；Day2 ELITE 配波次 3 + 奖励 ×2.0；Day3 BOSS 配波次 2 + 增援 1 + 奖励 ×2.0。奖励倍率作用于金币、魂、战斗奖励、S 评级额外魂、掉落数量；上限 2.0。

### 4.3 大循环（三天）

Day1 → BOSS1 → 遗物三选一 → 英灵殿（圣坛）  
Day2 → BOSS2 → 遗物三选一 → 英灵殿（圣坛）  
Day3 → BOSS3（双形态）

三天是 Build 成型周期。前两天可试错，第三天木已成舟。英灵殿合并复活与转职入口：地图圣坛节点直接调用英灵殿界面，顶部提示"选择一个单位转职或复活"；点击存活单位转职，点击灰掉阵亡单位直接复活。

**Boss 实际配置（代码事实）**
- Day1 Boss：`boss_magic_001` 暗黑神官，未配置 mechanic。
- Day2 Boss：`boss_heavyrider_001` 铁砧黑骑士，未配置 mechanic。
- Day3 Boss：`boss_dragonlord` 初始 120 HP；HP<50% 触发 form3"终焉"220 HP，附 `ash_shield` 3 层、减伤 0.5。数据层有 form2"翼焰"（160 HP），但 phases 数组只引用 form3，实际只经历 2 阶段。双形态切换不扣魂火上限（`_boss_penalty` 接口存在但无调用）。
- 敌人强度倍率总开关关闭：`ENABLE_STRENGTH_MULTIPLIERS=false`，Boss/ELITE/杂兵/Day 属性倍率均为 1.0。

### 4.4 超循环（多局）

局内 → 魂 → 局外 NPC 升级 → 下一局更强。派遣进度、光环研究进度以"天"为推进单位——每过一天 Boss，局外推进一天。

| NPC | 成长线 | 生效阈值 |
|---|---|---|
| 守火者 | 魂火上限/初始魂火/单位解锁/属性上限/遗物精炼入口 | 亲密度 ≥10 上限 +1；≥15 初始 +1 |
| 灰烬铁匠 | 光环研究/遗物精炼/熔炉（武器升级已删） | 亲密度 ≥10 升级 -20%（本版未实现） |
| 游魂向导 | 派遣路线（剧情解锁） | 亲密度 ≥10 派遣时长 -1 天 |
| 角斗士 | 竞技场/隐藏转职/词条解锁 | 亲密度 ≥10 参与费 -50% |

亲密度本版不会自动增长；所有阈值判定保留，数值需 GM 或剧情 effect 手动设置。隐藏 NPC 每 3 局出现一次，出售死眠之钥、标签定向器、Boss 情报、魂火阈值调节器；不卖直接橙装。

## 五、七组核心张力

### 5.1 留存 vs 挥霍（魂火的长线规划）
花掉：变强，但可能进入枯竭，导致下个节点开局失去燃烧态移速和溅射优势。留存：跨节点继承，带着满层魂火进下一场硬仗，甚至开局第一刀打出魂火爆发。不留存的代价是"下个节点开局时的战力真空"。

### 5.2 质变 vs 标签权重（Build 方向的锁定）
转职选 A 分支 → 获得 A 标签 → A 标签主导商店刷新。转职是押注。商店偏向 A 后，反向购买 B 标签装备性价比低。问号节点标签权重、胜利条件标签偏向、标签定向器，让标签权重更可感知、可干预。

### 5.3 派遣 vs 出战（阵容的零和博弈）
派遣单位本局不能出战；路线同时只能派一个；匹配标签 +1 魂；时长 1-3 天。双重决策：派谁 + 去哪。

### 5.4 熔铸 vs 保留（伤亡的装备化）
熔铸一个单位，本单位 `is_dead=true`，获得专属 buff 防具。弱单位熔铸 → 防具数值少；强单位熔铸 → 防具数值多但失去主力。打通"伤亡 → 装备深度"通路。熔铸防具不可修改、无词条/无方向/不可卖/不可覆盖，锁定在亡者身上，需复活取回。

### 5.5 高效 vs 稳妥（评级系统）
`score = 存活比例×0.4 + (1-血量损失比)×0.4 + 回合得分×0.2`；回合得分 = `clamp(1-回合数/(20×波次归一化),0,1)`。S ≥0.9（额外 +5 魂）；A ≥0.75（+1 魂）；B ≥0.55；C 其他。不同胜利条件调整公式：占领看守点回合；夺旗看回合数；突进看损失与回合。

### 5.6 绝对代价 vs 极限破局（死眠之钥）
跨局攒 200 魂 → 隐藏商人买唯一一把钥匙 → 局内祈祷刷出宝箱。代价跨局、赌性局内、报偿延迟。入口稀缺（每 3 局出现一次）、价格痛感（5-6 局通关积攒）、使用赌性（只保证高级开启有史诗/遗物级提升，不保证遇到宝箱）。

### 5.7 深化 vs 广度（遗物精炼）
在铁匠处花 150 魂精炼，加性提升（如首击必暴变前两次）。不增加新轴，只做深化。真正的选择是"精炼我已有 Build 里最核心的那个遗物"；魂通常只够精炼 1-2 个。

## 七、核心系统详解

### 7.1 魂火系统
接入点：移动 +1（燃烧）、溅射 50%（燃烧）、暴击 +0.5（枯竭）、无受伤放大。消耗：主动技能 2-3、购买光环 4-8、破盾 1/层、魂火爆发（全部）。结算：战后保留至下个节点；胜利写回持久层，失败/放弃保持战前值。

波次间魂火不重置。高收益节点 `reward_multiplier` 直接乘在战斗奖励的魂/金币上；命中 +1 是固定值，不受乘算。

**与 v4.7 差异**：删除战后 1:1 转魂；删除枯竭 ×1.3 受伤；删除多余魂火状态显示；归零无扣血；击杀不额外发魂火。

### 7.2 装备系统
独立可配置装备为**防具、遗物、光环**三类；武器不再是独立物品，仅作为单位内联数值存在（见下文）。

**武器（内联单位）**：武器数值（攻击/品质/补正/射程/穿透/heavy/magic/heal）直接内联到 `unit_data.json`；升级系统删除，铁匠铺不再提供武器升级。heavy 类武器基础倍率 ×1.2；携带 charge 核心特性且 `charge_stacks>0` 时，最终伤害 `×min(1.0+0.2×层数,1.6)`——1 层 ×1.2、2 层 ×1.4、3 层及以上 1.6 上限；攻击后清空层数。charge_stacks 上限 5，但受 1.6 约束，3 层到顶。

**防具**：无升级，只计算减伤率、附加属性、品质倍率、词条、方向连通。方向系统：每件防具实例有 `direction`（UP/DOWN/LEFT/RIGHT/VERTICAL/HORIZONTAL/DIAG_NE_SW/DIAG_NW_SE）；掉落时按 `enable_direction=true` 30% 概率带方向。方向重 roll：铁匠铺 120G；单箭头换另 3 个单箭头之一；双箭头在 ↕/⤢/⤡ 三选一。

**连通组（v5.1 降权）**：跨单位相邻槽位方向对接时连成一组，按组大小 + 跨单位数提供攻击%/防御%/HP% buff。**数值封顶从 +30% 降到 +15%**——连线从"必修课"降级为"加分项"：玩家连不成线也能靠标签套装成型，连上就是白赚。跨 3 单位超级网额外给**功能性奖励**（全队开局 +2 护盾；超级网 +1 魂火）。星号标识组等级（★★★为 5 件以上超级连通网）。UI：悬停带箭头防具时同组槽位亮黄框，左侧显示"★ 已链接：X 件防具（跨 Y 个单位）"。支持一键自动配装，生成攻击流/防御流/平衡流三方案，可选是否允许交换单位位置。

**套装判定（v5.1）**：同标签套装按**单位内**统计（每单位 2 防具槽），2 件即生效（tier1 基础数值）；2 件中只要有 1 件 epic+ 即触发 tier2 质变（强力机制）。全队交叉套装（两标签各 2 件）作为辅助层并行存在，不抢单位 Build 特色。效果统一从 `SetBonusManager.get_unit_set_effects()` 出口读取，tier 判定只做一次。

**Build 视觉反馈（v5.1）**：防具图标背后垫一个 24×24 标签配色方块（烈焰红/轮回青/灰烬灰/守护蓝/献祭暗红/余烬金），代表该装备的 Build 方向；装备界面左侧"Build:"统计条实时显示全队各标签件数，达 2 件高亮并提示"已激活 2 件套效果"。

**商店展示（v5.1）**：商店卡片绑定真实的 `ItemInstance`（含本次刷新 roll 出的词条），悬浮直接显示该实例词条；刷新只重 roll 商品与词条，不使用临时副本替代显示数据。商店防具与队伍防具共用标签配色、图标与词条展示口径，避免"看到的价格/词条"和"买入后的装备"不一致。

**商店标签供货（v5.1 平衡）**：商店仍按队伍标签 / 购买记录 / 低语定向给热门标签加权供货（默认 80% 格子给前 2 标签），但单页增加同标签上限——6 格商店同一标签最多 3 件（约为 `SHOP_SIZE × 45%`，最低 2）。达到上限后该标签退出本页候选，改由次热门标签或通用池补位；若整池都是该标签则允许溢出，避免空格。这样"押守护"仍比冷门标签更容易出货，但不会一屏全是守护蓝。

**三层合成配方树**：Tier1 common+common→rare；Tier2 rare+common/rare→epic；Tier3 epic+epic→legendary。配方无门槛，匹配直接产出。  
**熔合**：2 件同标签紫装→橙装：烈焰→烈焰之羽、轮回→无尽轮回、灰烬→爆燃之核、守护→熔岩壁垒、献祭→不灭余烬、余烬→不灭薪火。  
**重铸**：epic 防具 500 金币重 roll 词条。  
**熔炉**：合成产物/熔铸产物进熔炉二次处理。  
**熔铸防具**：`melt_` 前缀；无词条、无方向、不可卖、不可合成、不可熔合、不可被其他装备覆盖；数值由 `melt_armor_effect` 提供（攻击 +N + 特殊效果：暴击伤害/防御/攻击%/减伤/治疗/反击）；出产进 `pending_sacrifice_rewards`，需手动装备或丢弃。

### 7.3 词条系统
累积型（crit/bleed/parry 等）和主动型（active_charge/active_fireball 等）。解锁路径：default 5 个（教程自动）、soul 19 个（竞技场通关选择）、story 0 个。

**词条数量梯度（v5.1「明显」方案）**：所有品质都有词条且数量拉开——`common 1 / rare 2 / epic 3 / legendary 4`（旧版 common 0 / rare 1 / epic 2 / legendary 3 已废弃）。基础词条（攻击/防御/HP）降为 common 作为通用池。

**词条标签倾向（v5.1）**：`AffixManager.roll_affixes` 改为两阶段抽取——先抽与该防具标签匹配的**专属词条**，再用**通用词条**补满，按 type 去重。效果：烈焰防具必出攻击/暴击/火焰伤害/物穿，守护必出免暴/反击/护盾，轮回必出回血/魔穿，献祭必出吸血/治疗，余烬必出回魂火，灰烬必出移动/护体——玩家拿到就知道给谁穿。灰烬、轮回、守护、献祭、余烬各补了 common 档低阶专属词条，保证低品质也有流派基因。

词条穿透：`affix_pierce_physical` 破甲（物穿 5-10%，epic，烈焰）、`affix_pierce_magic` 奥术穿透（魔穿 5-10%，epic，轮回）。epic 起步让穿透反制成为中期策略；多槽穿透加法叠加。

其他防具词条：`affix_cycle_regen` 每回合回复 3-6% 最大 HP；`affix_guard_shield` 战斗开始获得 2-5 点护盾（走 `start_shield` 影响物/魔减伤率）；`affix_anti_crit` 受到暴击伤害 -20%~-40%；`affix_soul_fire_gain` 击杀回魂火 +1（legendary）。词条等级 0-3 级，由竞技场 EXP 累积（阈值 `[0,100,300,600]`）。

### 7.4 熔铸系统（原献祭）
定位：伤亡价值化，从"给魂火"改为"给装备深度"。入口：FORGE 铁匠铺第 3 tab"熔炉"或直接拖单位到熔炉槽。流程：拖单位→确认（若队伍只剩 1 人警告全灭）→单位 `is_dead=true`、HP=0→生成 `melt_<单位名>` 防具进 `pending_forge_rewards`→玩家在待领取区装备。产出示例：`melt_swordsman` 残锋战甲 攻击+5、攻击+20%、物减10%、魔减8%；`melt_mage` 残智长袍 攻击+5、攻击+25%、物减8%、魔减10%；`melt_cleric` 残光法袍 攻击+5、治疗+40%、物减8%、魔减12%；`melt_axeman` 残焰胸甲 攻击+5、暴伤+40%、物减8%、魔减8%。限制：不可修改、不可卖/合成/熔合、不可覆盖、不可拖进熔炉；装备锁定亡者，需英灵殿复活取回。熔铸第 3 个单位将导致全灭，本局结束（代码不禁止，界面警告）。

### 7.8 单位成长系统
四种成长：单位解锁（守火者，50-150 魂）；属性上限（守火者 5 级升级，费用 `[20,50,120,250,500]`，默认 Lv3 起，封顶 Lv6）；转职（英灵殿免费）；武器等级已删除。

属性面板 6 项：HP、力量、灵巧、智力、信仰、移动。感应 ARC 不出现在面板/属性上限/战斗主路径，仅内部次级字段保留。不新增速度（追击由灵巧差判定，阈值 4）；不新增闪避（只做词条）；不新增物防/魔防数值（防御为减伤率乘区）。

核心特性：`charge` 斧兵回合结束累积 1 层，攻击释放，每层 ×1.2 受 1.6 上限约束，3 层到顶；`dragon_might` 龙人相邻敌人攻击 -10%；`bulwark` 重甲相邻友军减伤率 +15%，受 75% 上限约束。

减伤率分层：单位模板基础物/魔减；防具加法；武器穿透；词条/遗物条件减伤或穿透；地形；魂火状态乘区已删除。伤害公式：`物理伤害 = 物理攻击 × (1 - 物理减伤率 + 物理穿透)`；减伤率 `clamp(单位基础+防具+词条+buff+地形,0,75%)`；穿透 `武器穿透+词条穿透`；最终 `max(攻击×10%, 上述伤害)`。`buff_damage_reduction` 与减伤率同源，加法叠加，受 75% 上限约束，不走最终乘区。

地形减伤率：平地 0/0；森林 10/0；山地 20/0（不可通行）；建筑 25/15；不可通行 0/0；墙 0/0。地形 AI 评分 `int((物减+魔减)*300)`。

| Streak | 金币 | 魂 | 敌人倍率 |
|---|---|---|---|
| 0 | 200 | 0 | 1.0 |
| 1 | 300 | 0 | 1.2 |
| 2 | 500 | 1 | 1.6 |
| 3 | 800 | 1 | 1.9 |

生存模式倍率 `[1.8,2.1,2.4]`。竞技场是纯 Build 验证场所，1v1 单挑，不涉及地形/站位；词条就绪即触发；主动技能就绪即触发，不受玩家手动控制。**代码事实**：竞技场 `ArenaBattle._calc_damage` 仍使用减法公式（`total_attack - defense`），与主线乘法不一致，为本版技术债；文档目标为统一乘法，但代码未完全切换。

### 7.10 剧情/对话系统
双数据源：`narrative.json` 的 `npcs` 子树（树形）+`standalone` 子树（扁平）。解锁条件：`min_altar_level` / `min_initial_level` / `min_dispatch_count` / `min_arena_clear` / `min_run_count` / `min_dialogue_count` / `after_dialogue` / `flags`（v5.1 已移除恒为 0 的 `min_weapon_max_level`，原 7 处剧情条件一并清除，相关剧情不再被永久锁死）。解锁类型：unit/relic/aura/route/talent/transform_branch。

亲密度本版不会自动增长；阈值判定保留，数值需 GM/剧情 effect。FORGE 低语每次进 FORGE 触发 1 条未看过低语（跨局不重复），Day1/2/3 各一次；奖励以情报/flag/解锁为主，不给大资源。隐藏 NPC 对话树 `merchant_first`（priority 10 首次）+`merchant_repeat`（priority 0 非首次）；对话只讲故事，UI 只交易。头像：单位从 `unit_data.json`/局外自定义读取；NPC 从 `narrative.json avatar` 读取；无头像隐藏头像框，文本占满全屏。

### 7.11 战斗系统
伤害公式主线：物理攻击 = 武器攻击×品质倍率 + 力量×系数 + buff，× (1+buff_attack_percent)，× (1+力量×relic_strength_scale_damage)；物理减伤 = clamp(单位基础+防具×品质+词条+buff_physical_reduction+buff_damage_reduction+地形+低血减伤,0,75%)；物理穿透 = 武器穿透+词条穿透；最终伤害 = `max(攻击×10%, 攻击×(1-减伤+穿透))`。无魂火状态修正。

暴击：`0.05 + 灵巧×0.005 + 品质加成 + 词条加成`；暴击倍率 `1.5 + 枯竭 +0.5 + 词条`，上限 2.0。追击：攻击方灵巧 ≥ 防守方灵巧 +4 → 追加一次普攻，不消耗魂火。闪避不进入基础公式，只做词条机制。品质倍率统一读 `CombatManager.QUALITY_MULT`（1.0/1.25/1.5/1.8）。

完整攻击流程：主动技能判定（消耗魂火，治愈同样扣费）→基础伤害+技能倍率+heavy 倍率→zeal/combo 累积→暴击判定→parry/block（盾反反死则终止）→应用伤害+屏震→命中回魂火 `on_hit(1)`→燃烧溅射→splash/aoe→击杀检查→Boss 双形态拦截→death animation→吸血/二次攻击/法术连击→反击→清理 charge 层数。

**v5.1 战斗落地口径**：套装、词条、交叉套装、连通组在玩家回合开始由 `TurnController` 统一应用，消费侧统一读 `SetBonusManager` 出口，避免同名不同义。魂火爆发的强制暴击分支同样读取 `buff_crit_damage_bonus`，因此烈焰 tier2 的暴击伤害 +30% 在爆发中也会生效。Boss 对话等待改为带超时的安全等待，并加入输入锁看门狗：玩家回合已就绪、无合法阻塞 UI 时若过渡/锁定持续过久，会强制解锁，避免偶发"进战斗后不能操作"。

**战斗层 / 持久层隔离（v5.1）**：防具、词条、套装、连通组对 `max_hp` / `move_range` 的加成按"临时增量"记录，战后胜利同步、单位阵亡、失败或中途退出时按增量回滚；`UnitData` 的升级写回不受影响，也不用整份 `duplicate()` 切断引用。结果是 Build 加成只在本场战斗生效，跨节点成长仍持久化。

AI：敌方远程站"能攻击到玩家的最远格"（`+100+距离×25`）；打不到时 `-80+地形分/2`（降权但不完全禁止）；全队无法攻击时主动压上；近战主动贴脸。敌方修女 HP<25% 无条件自愈；25%-50% 且危险区域优先自愈；HP<30% 保命移动；无治疗目标主动攻击；移动时优先站 staff 射程 4 外沿。绝望机制见 4.1。

胜利条件：全灭/占领/夺旗/突进。占领：玩家单位站目标格，每次玩家回合结束 +1，满 hold_turns 胜利，中途离开归零。夺旗：踩旗拾旗；旗手到终点胜利；旗手死亡旗帜原地保留。突进：击杀指定单位（未配置则击杀 Boss）胜利。`TurnManager.check_victory()` 只在 ANNIHILATE 目标下把敌人全灭算胜利；其他目标敌人全灭不算胜利；玩家全灭始终失败。顶部常驻短状态标签；波次无提前预告；增援从边缘出现直接激活；波次间魂火不重置；评级回合分按总波次归一化。

### 7.12 地图节点与死眠之钥宝箱
问号节点类型预设战斗/精英/宝箱/事件/商店/祭坛/派遣；标签权重影响概率；保底见 4.2。死眠之钥唯一来源是局外隐藏 NPC（200 魂）；单局携带上限 1；有钥匙时宝箱界面多"高级隐藏开启"按钮，消耗 1 钥匙。高级模式权重 `{gold:1, armor:2, relic:8}`，品质池 `["epic","legendary"]`，金币/魂 ×1.8~2.0；三选项类型严格不重复；没有中间态、没有额外彩头。`keys` 每局清零，`keys_bought` 跨局累计（仅清档归零）作为埋点。

### 7.13 祭祀场横屏探索
三屏：[左屏：废弃的侧厅] [中屏：祭祀场主体] [右屏：灰烬的角落]。中屏原有全部功能（入口门、4 个 NPC）；左右屏目前为空背景+标题，为未来内容预留。导航：左右箭头按钮（屏幕最左/最右竖长条，垂直居中），点击平滑滑到相邻屏（0.35 秒 EASE_IN_OUT），端点箭头 disabled。牺牲一点探索触觉换 100% 点击可靠性。

隐藏商人：每 3 局出现一次，随机落左/右屏固定位置（x=0.5 屏或 2.5 屏，y=80）。对应侧箭头变金色+闪烁（0.5 秒循环）；首次出现额外弹 toast（"……左边/右边好像有动静"，3 秒淡出）；玩家滑到商人那屏后箭头恢复普通色。隐藏不是"看不见"，是"要看一眼才看得见"。

### 7.14 遗物精炼系统
入口：灰烬铁匠第 2 tab"遗物精炼"（Tab 顺序：光环研究/遗物精炼）。消耗 150 魂/次，每件遗物只能精炼 1 次，跨局永久保留。加性提升，防数值爆炸。

### 7.15 战损与复活机制
火焰纹章式战棋规则：战后存活单位自动满 HP；阵亡单位 `is_dead` 同步局外，后续节点无法出战、不在战场生成；只能在地图圣坛节点（已与英灵殿合并）或 Day1/Day2 BOSS 战后英灵殿选择复活；复活后 HP 满可继续出战。出战前强制满血（`spawn_party_from_gamestate` 每单位生成前 `hit_points=max_hp`）。熔铸单位为"死亡+产出防具"；若未在英灵殿复活，熔铸防具锁定亡者；复活后从 `pending_sacrifice_rewards` 领取的熔铸防具解锁可用。阵亡单位普通防具在战斗结束同步时自动进待领取区；熔铸防具除外。

## 十一、设计哲学

- 资源唯一化：魂火贯穿一切，避免多资源复杂度。
- 状态嵌入化：资源不只是"多少"，而是"什么状态"。
- 标签接口化：6 标签作为系统间通信协议，横向扩展。
- 循环嵌套化：4 层循环让玩家始终在更长时间尺度下思考。
- 决策集中化：FORGE 作为决策爆发点，制造节奏对比。
- 延迟满足化：魂+熔铸+派遣+光环研究让每局都有"投资"面向。
- 伤亡价值化：熔铸换装备打通"损失→装备深度"通路。
- 解锁分层化：局外解锁（永久池）+局内获取（三选一/购买）。
- 接口化而非加系统：新机制必须挂到魂火/标签/魂，不新增第二资源、不新增第 7 标签。
- 局外投资→局内取舍闭环：死眠之钥、隐藏 NPC、标签定向器。
- 情报作为奖励：FORGE 低语、Boss 情报、商店偏向。
- 极端条件与绝对破局：死眠之钥是唯一凌驾日常循环的局外干预。
- 探索作为节奏：营地不是菜单，它是"地方"。
- 低成本"看看"是玩家情绪安全垫。
- 删掉冗余比新增更有价值。
- 深化而非扩张：遗物精炼/连通组是现有装备的第三、第四维度。
- 风险与报偿绑定：波次高收益节点让"打硬仗"和"拿更多奖励"直接挂钩。
- 特性与武器强绑定：charge+heavy_attack 让"斧兵+战斧"成为完整 Build 轴。
- "传说感"不需要新系统：高基础数值+高品质倍率+天赋绑定。
- 选择权是状态管理前提：是否花费魂火、是否押上全部（魂火爆发）交给玩家。
- 战损必须有痛感与里程碑意义：死亡代价具象化为"下个节点缺席"+"熔铸可选"。
- 属性负责底子，机制负责流派：6 属性+减伤率乘区；闪避/命中/格挡/免暴/异常/追击全部走词条/遗物/防具/转职。
- 光环是局内一次性消耗品：占被动槽 4 格之一，点击使用，用完即毁。
- 减伤率是乘区，不是防御值：模板基础、防具叠加、武器穿透、词条条件减伤；总上限 75%，最低保底 10%。
- 公式是设计语言：乘法让防御有边际递减、状态修正可走独立乘区；魂火是状态游戏，所以选乘法。
- 面板精简，机制不精简：砍掉物防/魔防两列，防御职责分散到六个接口。
- 状态有压力，但不该用掉血表达：归零不扣血，压力来自技能不可用、燃烧失效、破盾成本。
- 持久层与战斗层必须分离：战斗中变化不写存档，胜利写回，中途退出/失败保持战前值。
- 地形是减伤率接口，不是无效面板。
- 远程 AI 不送，是为了让玩家动：敌方远程站射程外沿，玩家必须主动移动 1 格。
- 治疗者首先是单位，其次才是治疗者：敌方修女无治疗目标会攻击，濒死会自愈。
- Boss 本体强，杂兵适度强：Boss 战强度曲线的克制（本版总开关关闭，待启用）。
- v4.7：命中回魂火优于击杀回魂火：把节奏从"攒击杀"变成"每次挥刀"，状态切换更频繁。
- v4.7：阵亡补偿是软压力：让"死人"有痛感也有一次反打机会，但不至于故意送人。
- v4.7：熔铸是"伤亡装备化"：不给魂火/魂，只给一件无法修改的橙装，让玩家在"练人 vs 换装"之间做超战略判断。
- v4.7：连通组是"摆位也是 Build"：把单位排列和防具方向作为新一层策略维度。
- v4.7：魂火爆发是"全押"的战术按钮：让归零不再只是被打回正常态，也可以是主动选择。
- v4.7：自动配装是"耐心友好"：手动摆位是策略，自动配装是保底。
- v4.7：删掉武器升级是设计减负：武器变成单位的一部分，铁匠铺从升级工坊变成光环/精炼/熔炉纯战略界面。
- v4.7：熔铸防具"不可修改"是刻意限制：不给词条/方向/不能卖，避免变成通用升级。
- v4.7：删除枯竭受伤放大是压力重估：归零已是压力，再加受伤放大属于双罚。

**克制，是本作最大的设计增量。**

## 十二、以小搏大

它没有发明新机制——熔铸、派遣、套装、魂火状态、光环，都是肉鸽里见过的。独特之处是组织方式：一个资源（魂火）扛起三重身份；一组标签（6 个）横向贯穿所有系统；一层循环（4 层）让短决策有长后果；一种资源（魂）连接局内与局外；两种"解锁+使用"双层（遗物/光环）让永久投资有局内取舍；一种"极致豪赌"破局点（死眠之钥）；一种"条件触发隐藏 NPC→卖选择权/情报"超循环入口；一组"波次+胜利条件"让魂火状态有战术差异；一段"营地横屏探索"让回营地从功能动作变成空间体验；一套"目标短状态标签+保底机制+双模式宝箱"让设计意图落到玩家手指上；一组"高收益波次节点"让硬仗有硬回报；一套"遗物精炼"让已有遗物有第三维度；一个"特性+武器强绑定"的 Build 轴（斧兵+战斧）；一个"战损满血结算+圣坛英灵殿合并"的反馈闭环；一个"普攻/技能选择菜单"的自主决定权；一套"6 项单位属性+减伤率乘区"的轻面板、重机制属性方案；一套"主线与竞技场统一口径"的伤害公式目标；一套"词条穿透"让堆减伤有反制；一套"地形减伤率"让站位有真实收益；一套"远程 AI 不送+近战 AI 贴脸"的差异化移动；一套"治疗者自愈+攻击"的完整 AI；一套"Boss 本体强、杂兵适度强"的强度曲线（待启用）；一套"魂火持久层/战斗层分离"的存档一致性；一套"归零无掉血"的软压力状态设计；一个"删掉冗余"的设计动作。

v5.0 增量：魂火跨节点继承让长线规划更重；删除武器升级让铁匠铺更纯；6 属性移除 ARC；英灵殿合并；战损自动回收；AI 大修；连通组 UI；枯竭无受伤放大。它把"资源选择游戏"变成了"状态管理游戏"。魂火的独特之处不是数值强度，而是让每一次花费都是一次身份转变。
