# 《魂火》v6.0 玩法设计文档（装备减负 · 选择组成 Build）

> 状态：v6.0 设计冻结版，日期 2026-11-18。  
> 本文描述**目标玩法**。除 v5 已落地的战斗、地图、魂火、存档、编辑器等实现外，v6 新规则**尚未修改代码**。  
> 不兼容老存档；数据结构可直接重命名、重建。  
> 承接方案：`EquipmentSlimPlan.md`、`EquipmentOneClickPlan.md`、`EquipmentUIIterationPlan.md`；冻结摘要见 `EquipmentBuildRefactorSummary.md`。

---

## 一、版本定位

v5 把《魂火》做成“状态管理 + 标签配装”的肉鸽：魂火负责短循环，6 标签贯穿系统，FORGE 是决策爆发点。实际游玩后暴露的问题是：**装备系统操作强度过高**。玩家大量时间花在比较词条、摆方向、凑连通、管理背包和覆盖装备上，而不是表达 build。

v6 的核心转向：

> **玩家通过选择组成 build，而不是花时间配装。装备的重要性来自“第一件即觉醒机制”，不是来自操作复杂度。**

v6 把玩家日常操作压缩为三类：

1. 开局主动技能 roll → 点单位落位；
2. 战后防具 roll → 点单位落位 / 覆盖 / 放弃；
3. BOSS 后或宝箱遗物三选一。

系统承担所有计算：槽位、方向、连通、词条数值、品质上限、套装判定、成本结算。

### v6 相对 v5 的核心变更

1. 地图装备界面从“可调整装备 / 词条 / 方向”变为**只读 Build 查看器**。
2. 商店不再是一个地图节点功能；防具获取改为**战后金币 roll**。
3. 开局选 3 单位后，从这些单位可装备的主动技能中 roll 3 次，形成随机起点。
4. 每单位技能词条上限 2 格：第 1 格开局 roll，第 2 格转职获得；两格锁定。
5. 防具从数值套装改为**单件觉醒机制 + 同流派并入升 Lv**。
6. `armor_slots` 语义改为**机制槽**：一个流派占一格，同流派后续防具不占新槽。
7. 魂栈去掉商店 / 铁匠 / 光环，只保留**熔铸单位**这一单一功能。
8. 光环并入遗物：多数为持续型，少数产魂火光环为消耗型遗物。
9. 连通、箭头、装备界面单位交换位置从玩家层移除。
10. 单位升级改为战斗内累计经验、战后自动升级；装备界面不再有升级按钮。
11. 战后结算不再送防具；宝箱不再提供防具选项。
12. 竞技场本轮不同步，先稳定主线战役。

### 保留的 v5 骨架

魂火三态、命中回魂火、魂火跨节点继承、六流派标签、四层循环、七组张力、熔铸单位、遗物三选一、局外魂成长、派遣、剧情、竞技场、编辑器生态、伤害公式、减伤率 75% 上限、最低保底 10%。

## 二、核心体验

v6 的体验重点从“我把装备摆对了吗”转为：

- 这局我的三个单位分别拿到什么主动技能？
- 这件防具要开新流派，还是喂给已有流派升 Lv？
- 这个流派是该给主核，还是给副核开第二机制？
- 满槽时，我愿意放弃哪一个机制？
- 遗物三选一，是补队伍短板，还是强化主流派？

玩家不再做算术题。每个选择都有一句话后果预览：

```text
给剑士 → 觉醒烈焰（攻击附带灼烧）
给守卫 → 并入烈焰 Lv2
给法师 → 新增守护反弹（主流派仍烈焰）
```

装备仍是 build 核心，但它的价值表达从“+10% 攻击”变成“这单位从此会灼烧 / 反弹 / 击杀回魂火”。

## 三、核心循环

### 3.1 开局循环

```text
选择 3 个单位
  → 生成主动技能 roll 池
  → roll 3 次，每次出 1 张技能卡
  → 点单位落位
  → 进入地图
```

- roll 池 = 已选 3 单位 `compatible_units` 的并集。
- 3 次 roll 不重复同一技能 ID。
- 不提供重掷。
- 不兼容单位灰显并说明原因。
- 点击单位即锁定，不能互换、不能撤销。
- 转职后获得第 2 格技能词条，固定内容、灰显不可操作。

主动技能覆盖：

| 单位 | 可 roll 的主动技能 |
|---|---|
| archer | 狙击 |
| cleric | 群体治愈 |
| mage | 火球 |
| swordsman | 冲锋 |
| spearman | 冲锋、贯穿 |
| pegasus | 俯冲、狙击 |
| armored | 蓄力斩、嘲讽 |
| axeman | 蓄力斩、嘲讽 |
| dragonborn | 贯穿、火球、龙息 |

任意 3 单位并集最小为 3 个技能，刚好支持 3 次不重复 roll。

### 3.2 战斗循环

微循环仍是魂火状态管理：

```text
接敌 → 命中 +1 魂火 → 燃烧 / 枯竭 / 正常切换 → 技能与普攻取舍
```

战斗内累计经验，战后自动升级。玩家不再在装备界面花金币手动升级单位。

### 3.3 战后循环

```text
战斗胜利
  → 结算金币 / 魂 / 解锁
  → 防具 roll（金币，每次 +50G）
  → 领取台：装备 / 并入 / 重铸 / 覆盖 / 放弃
  → 继续地图
```

战后结算不再出现防具卡片，不再有稀有防具掉落。

### 3.4 节点循环

```text
START / NORMAL / ELITE / BOSS
  → 魂栈：熔铸单位（无商店、无铁匠、无光环）
  → 宝箱：遗物 / 金币 / 魂，无防具
  → BOSS 后：遗物三选一
  → 英灵殿：复活 / 转职
```

## 四、玩家决策密度

| 阶段 | 密度 | 决策 |
|---|---|---|
| 开局选 3 单位 | ★★★ | 阵容与起点 |
| 开局主动 roll | ★★★★ | 技能给谁，固定随机起点 |
| 战斗内 | ★★ | 普攻 / 技能 / 魂火爆发 / 站位 |
| 战后防具 roll | ★★★★ | 流派落点、覆盖取舍、金币投入 |
| 魂栈熔铸单位 | ★★★★ | 失去单位换机制防具 |
| BOSS / 宝箱遗物 | ★★★ | 持续型 / 消耗型遗物取舍 |
| 转职 | ★★★★ | 获得第 2 技能词条与被动 |
| 地图装备查看 | ★ | 只读理解 build |

FORGE 不再是“商店 + 铁匠铺 + 合成 + 熔铸 + 光环 + 刷新”的高压节点，而是低频战略节点。

## 五、核心系统详解

### 5.1 魂火系统

魂火仍是一个数值、三重身份：

| 身份 | 表现 |
|---|---|
| 资源 | 主动技能、魂火爆发、破盾等消耗 |
| 状态 | 燃烧 / 正常 / 枯竭，归零并入正常并 HUD 标记“熄” |
| 续航 | 战后 100% 写回持久层，跨节点继承 |

三态：

| 状态 | 触发 | 效果 |
|---|---|---|
| 燃烧 | > 50% 上限 | 移动 +1，攻击溅射 50% |
| 正常 | 20%–50%，或归零 | 无 |
| 枯竭 | 0 < 魂火 < 20% | 暴击伤害 +50% |

获得口径：

- 命中 +1，包含普攻、追击、溅射、AOE、反击等命中结算。
- 我方单位阵亡 +5。
- 归零态击杀 +1 作为触底反弹补偿。
- 装备 / 遗物 / 流派机制的击杀回魂火钩子按新机制结算。
- 战斗奖励发放“魂”，不发放魂火。

主动技能消耗必须在释放瞬间前扣，并显示“消耗 N 魂火”；命中 / 击杀收益在之后结算，避免净变化看起来为零。

魂火爆发：≥3 魂火时可消耗全部，强制暴击并附加额外伤害，使用后强制结束行动。

### 5.2 流派与标签

6 个流派：烈焰 / 轮回 / 灰烬 / 守护 / 献祭 / 余烬。单位不再预设流派，流派身份每局由玩家选择形成。

| 流派 | 机制 | 战斗接线点 |
|---|---|---|
| 烈焰 | 攻击附带灼烧，可叠层 | 伤害结算 |
| 守护 | 格挡时反弹伤害 | 受击 / 格挡 |
| 轮回 | 击杀回 2 魂火 | 击杀结算 |
| 献祭 | 每回合扣血换攻击 | 回合开始 / 攻击 |
| 灰烬 | 移动后留下燃烧地块 | 移动 / 地形 |
| 余烬 | 魂火耗尽时下击必暴 | 魂火归零 / 暴击判定 |

具体数值可调，但原则是：**一件即完整生效、一句话能说清、穿上就改变打法**。

### 5.3 主动技能词条

技能上限：每单位 2 格。

| 格位 | 来源 | 规则 |
|---|---|---|
| 第 1 格 | 开局 roll | 从单位可装备技能中 roll，点单位锁定 |
| 第 2 格 | 转职 | 转职分支固定获得，灰显不可操作 |

规则：

- 两格技能词条都不可互换、不可重洗、不可覆盖。
- 选定离手；装备界面只展示，不操作。
- 主动技能释放时显示魂火消耗与冷却。
- 若技能与单位某流派机制同标签，可触发共鸣加成，具体数值在烈焰样板阶段验证。

### 5.4 防具与机制槽

防具不再按“一件占一格、叠数值”处理，而是按“机制引擎”处理。

```text
已用机制槽数 = 单位当前觉醒的不同流派数
某流派 Lv   = 该流派吞掉的同流派防具贡献
```

规则：

1. 第一件同流派防具：觉醒完整机制，占 1 个机制槽。
2. 第 2/3/4 件同流派防具：并入同一机制升 Lv，**不占新槽**。
3. 品质决定 Lv 上限：common 1 / rare 2 / epic 3 / legendary 4。
4. 不同流派：开新机制槽，受单位 1/2/3 槽限制。
5. 满槽时：只能放弃或覆盖已有机制，不能塞进背包。
6. 词条出生即定、只读、不可互换。
7. 方向、连通组、单位交换位置从玩家层移除。

单位机制槽名单：

| 槽数 | 单位 | 理由 |
|---|---|---|
| 1 槽 | armored、dragonborn | 本体强，单机制专精 |
| 2 槽 | spearman、pegasus、archer、axeman、cleric | 大部分单位，主流派 + 副流派 |
| 3 槽 | swordsman、mage | 多分支成长，靠多机制差异化 |

建议底层字段从 `armor_slots` 改为 `mechanism_slots`，UI 统一显示“流派槽”。

### 5.5 战后防具 roll

战后结算界面只显示金币、魂、解锁项。防具通过金币 roll 获取。

价格：

| 项 | 数值 |
|---|---|
| 单次 roll 起价 | 100G |
| 同场战后每次递增 | +50G |
| 重置时机 | 离开结算界面 |
| 品质等级升级 | 200 / 500 / 1200 / 2500 / 5000 |
| 品质权重 | 复用 `shop.quality_weights` 6 档 |

领取台动作：

| 动作 | 规则 |
|---|---|
| 装备 / 并入 | 无该流派则觉醒；已有则升 Lv |
| 重铸流派 | 500G，不改变品质与词条 |
| 合并 | 200G，仅同流派同机制升层 |
| 覆盖 | 满槽时选一条机制覆盖，二次确认，0G |
| 放弃 | 直接丢弃，0G |

### 5.6 遗物系统

v6 不再有独立光环系统。所有原光环并入遗物池，用 `lifetime` 区分：

| 类型 | 行为 |
|---|---|
| persistent | 获得后本局持续生效 |
| consumable | 战场点击使用，本场战斗生效，战斗结束移除 |

发放口：

- BOSS 战后三选一；
- 宝箱节点；
- 局外研究只负责解锁，不再在魂栈购买。

遗物分类：

| 原光环 | 新类型 | 效果 |
|---|---|---|
| 薪火相传 | consumable | 战场使用：本场每回合开始 +1 魂火，战斗结束移除 |
| 轮回流转 | consumable | 战场使用：本场击杀 +1 魂火，战斗结束移除 |
| 灰烬之拥 | persistent | 本局受伤 -10%，反击 +30% |
| 焚身 | persistent | 本局全队攻击 +15% |
| 铁壁 | persistent | 本局全队双减 +10% |
| 血脉燃烧 | persistent | 本局击杀治疗 15% HP |

分类原则：只有直接产出魂火的才做消耗型，其余全部持续型。

原有 9 个遗物继续作为 persistent 遗物保留；遗物精炼保留，每件 1 次、150 魂、跨局永久。

### 5.7 单位成长

v6 单位成长原则：**自动为主，不制造额外操作**。

- 战斗内累计经验：击杀、造成伤害、治疗、存活等贡献进入经验条。
- 战后自动结算升级。
- 升级只增加基础属性和已配置的等级机制，不弹新选择。
- 每局净增约 1~2 级，避免等级掩盖 build 差异。
- 装备界面不再显示升级按钮，也不再花金币升级。
- 转职仍由英灵殿提供，并写入第 2 格技能词条与固定被动。

`unit_level_up_cost` 可保留为历史配置，但不再作为玩家可见消耗。

### 5.8 战斗系统

伤害公式与核心常量沿用 v5：

```text
物理攻击 = 武器攻击×品质倍率 + 力量×系数 + buff
         × (1+buff_attack_percent)
         × (1+力量×relic_strength_scale_damage)

物理减伤 = clamp(单位基础+防具+词条+buff+地形+低血减伤, 0, 75%)

最终伤害 = max(攻击×10%, 攻击×(1-减伤+穿透))
```

暴击：

- 基础 5%；
- 每点灵巧 +0.5%；
- 暴击伤害倍率 1.5，上限 2.0；
- 枯竭时 +0.5 暴伤；
- 余烬机制在魂火耗尽时提供下击必暴。

攻击流程：

```text
主动技能判定与前扣魂火
  → 基础伤害 + 技能倍率 + heavy 倍率
  → 流派机制触发（灼烧 / 反弹 / 回魂火 / 扣血换攻等）
  → 暴击判定 → parry/block → 应用伤害
  → 命中回魂火 on_hit(1)
  → 溅射 / AOE → 击杀检查 → 击杀钩子
  → Boss 形态拦截 → 吸血 / 连击 / 反击 → 清理临时状态
```

流派机制必须走统一出口，避免同名不同义。战斗层与持久层继续隔离：Build 临时增量胜利后同步，失败 / 中途退出回滚。

### 5.9 地图节点

| 节点 | v6 功能 |
|---|---|
| START / NORMAL / ELITE | 战斗；战后防具 roll |
| BOSS | 战斗；战后遗物三选一；无防具掉落 |
| TREASURE | 遗物 / 金币 / 魂三选一，不再给防具 |
| FORGE（魂栈） | 熔铸单位为单一功能；无商店、铁匠、光环 |
| CHAPEL / 英灵殿 | 复活、转职；转职写入第 2 技能格 |
| QUESTION | 沿用 v5 随机节点与保底规则 |

问号保底、高收益节点、波次、胜利条件、Boss 双形态等 v5 地图规则保留。

### 5.10 熔铸单位

保留为单一功能节点：牺牲一个单位，获得该职业专属 `melt_` 防具。

- 单位 `is_dead = true`，HP = 0。
- 产出防具不可修改、不可卖、不可合成、不可覆盖。
- 熔铸防具绑定到亡者，复活后可取回。
- 熔铸后第 1/2 技能格随单位死亡失效。
- 熔铸第 3 个单位会导致队伍全灭，本局结束。

v6 不再把熔铸防具作为普通防具来源；它是伤亡价值化出口，不进入防具 roll 池。

### 5.11 竞技场

本轮竞技场保持 v5 规则：

- 4 场普通战 → 4 连胜 → 撤离 / 生存。
- 无魂火、无地形、无全局遗物 / 光环 buff。
- 伤害公式与主线一致：减伤率乘区 + 保底。
- 商店 / 铁匠铺 / 词条解锁等暂不同步 v6。

等主线 build 规则稳定后，再单独做竞技场对齐。

### 5.12 数据与编辑器

字段调整：

| 旧 | 新 |
|---|---|
| `UnitData.armor_slots` | `mechanism_slots` |
| `ItemInstance.direction` | 玩家层不再暴露；内部生成可停用 |
| 独立 `auras.json` 局内购买 | 并入遗物池，`lifetime` 字段区分 |
| 技能词条可拖拽 | 固定 2 格，只读展示 |
| 单位金币升级按钮 | 删除，经验自动升级 |

`GameDataEditor` 需适配：

- 遗物编辑器增加 `lifetime` 字段；
- 防具编辑器增加流派机制字段，弱化旧词条 / 方向编辑；
- 特技编辑器增加 roll 池标记与 `compatible_units` 校验；
- 数据校验检查技能池覆盖、机制槽名单、品质上限表；
- 旧存档相关迁移入口不保留。

## 七、试玩观察指标

### 目标区间

- 开局 roll 用时 <45 秒。
- 战后防具 roll + 领取用时 <60 秒。
- 魂栈停留 <60 秒。
- 燃烧态占比 40–60%。
- 枯竭态占比 15–30%。
- 归零 <10%。
- 三天通关率 >30%。
- 主动技能消耗提示可见率 100%。
- 防具 roll 覆盖 / 放弃决策出现率 >30%。
- 遗物三选一跳过率 <20%。

### 人工观察

- 玩家是否能一句话说出自己单位的 build。
- 同单位不同开局技能是否真的产生不同玩法。
- 同流派并入升 Lv 是否有即时爽感。
- 满槽覆盖是否痛但不困惑。
- 1 槽单位是否显得过于单薄。
- 3 槽单位是否造成认知负担。
- 消耗型遗物是否产生“现在用还是留着”的判断。
- 玩家是否还会寻找“方向 / 连通 / 词条重洗”等旧操作。

### 主要风险

1. 六流派机制接线与竞技场对齐工作量大。
2. 防具 roll 价格沿用商店数据，节奏可能偏贵或偏便宜。
3. 开局无重掷增加运气方差。
4. 技能与流派共鸣数值未定。
5. 3 槽单位前期可能过强或信息过载。
6. 删除连通 / 方向后，部分老玩家可能感到深度下降。
7. 竞技场暂不同步，短期会出现两套装备口径。

## 八、设计哲学

- **选择而非计算**：玩家定流派、定给谁、定覆盖谁；系统跑腿。
- **单件即机制**：第一件装备就改变打法，不靠凑数。
- **同流派并入**：后续装备升同一条机制，不制造背包。
- **槽位是引擎数**：单位 1/2/3 槽代表能同时开几个流派。
- **技能是随机起点**：roll 池受单位可装备限制，不写死流派身份。
- **转职是固定第二格**：不被 roll、不被覆盖，保持身份感。
- **遗物统一化**：取消独立光环系统，只保留持续型 / 消耗型两种生命周期。
- **成长自动化**：等级不再制造操作，build 差异优先于等级差异。
- **删除冗余比新增更有价值**：方向、连通、背包管理、商店比价都退出玩家层。
- **装备重要性靠机制表达**：不是让玩家更忙，而是让每次选择更有后果。
- **主线优先**：竞技场等外围系统暂不跟随改动，先验证核心 build 手感。
