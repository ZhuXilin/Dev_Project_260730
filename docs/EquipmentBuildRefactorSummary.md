# v6.0 装备减负重构 · 冻结总结

> 版本：v6.0 设计冻结版 · 日期：2026-11-18  
> 状态：**设计已冻结，主线代码已落地（2026-11-18）**；落地清单见 `GameplayDesignDoc.md` 第十章。  
> 承接文档：`EquipmentSlimPlan.md`、`EquipmentOneClickPlan.md`、`EquipmentUIIterationPlan.md`、`GameplayDesignDoc.md`。

---

## 一、目标与判断

本次改造不是“删掉商店 UI”，而是把装备系统从**背包管理 / 数值叠加**改成**落点选择 / build 表达**。

核心目标：

1. 玩家通过选择组成 build，而不是花时间配装。
2. 装备的重要性来自“第一件即觉醒机制”，而不是操作复杂度。
3. 玩家日常操作收敛为三类：
   - 开局主动技能 roll → 点单位落位；
   - 战后防具 roll → 点单位落位 / 覆盖 / 放弃；
   - BOSS 后或宝箱遗物三选一。
4. 系统承担所有计算：槽位、方向、连通、数值口径、套装判定。

---

## 二、核心循环

```text
选 3 个单位
  → 主动技能 roll × 3（每次点单位落位，锁定离手）
  → 战斗（经验自动累积）
  → 战后结算（金币 / 魂 / 解锁，不再送防具）
  → 防具 roll（金币换落点选择）
  → 节点分流：魂栈熔铸单位 / 宝箱与 BOSS 遗物
```

---

## 三、冻结决策清单

| # | 议题 | 冻结结论 |
|---|---|---|
| 1 | 地图装备界面 | 改为只读 Build 查看器；不再调整装备、词条、方向、单位位置 |
| 2 | 开局主动技能 roll | 只从已选 3 个单位各自可装备的主动技能并集中 roll；3 次不重复；不提供重掷 |
| 3 | 技能词条上限 | 每单位 2 格：第 1 格来自开局 roll，第 2 格来自转职；两格均锁定、灰显、不可互换 |
| 4 | 战后结算 | 只结算金币、魂、解锁项；不再赠送防具 |
| 5 | 战后防具 roll | 花金币 roll 防具；玩家选单位落位；满格选覆盖或放弃 |
| 6 | 魂栈节点 | 去掉商店、铁匠铺、光环页；保留熔铸单位为单一功能节点 |
| 7 | 光环 / 遗物 | 遗物统一为局内遗物池；多数为持续型，少数原光环为消耗型子类型 |
| 8 | 流派计算 | 第一件同流派觉醒机制；后续同流派并入升 Lv；品质决定 Lv 上限 |
| 9 | 连通 / 箭头 / 交换位置 | 从玩家层移除；装备界面单位交换位置删除 |
| 10 | 单位升级 | 战斗内累计经验、战后自动升级；装备界面不再有升级按钮 |
| 11 | 竞技场 | 本轮不同步，先稳定主线战役 |
| 12 | 老存档 | 不兼容；可直接重命名字段与重建数据 |

## 四、关键规则

### 4.1 主动技能 roll

- roll 池 = 已选 3 个单位 `compatible_units` 的并集。
- 每次 roll 产生 1 张技能卡 + 3 个单位落点预览。
- 不兼容单位灰显并说明原因。
- 3 次 roll 不重复同一技能 ID。
- 点击单位即锁定，不能互换、不能重掷。
- 转职获得第 2 格技能词条；转职前第 2 格为空且灰显。

当前技能覆盖：

| 单位 | 可 roll 的主动技能 |
|---|---|
| archer | 狙击 |
| cleric | 群体治愈 |
| mage | 火球 |
| swordsman | 冲锋 |
| spearman | 冲锋、贯穿 |
| pegasus | 俯冲、狙击 |
| armored | 蓄力斩、嘲讽 |
| axeman | 蓄力斩、嘲讽 |
| dragonborn | 贯穿、火球、龙息 |

任意 3 个单位的并集最小为 3 个技能，刚好支持 3 次不重复 roll。

### 4.2 机制槽 / 防具槽

旧规则：一件防具占一个防具槽。  
新规则：一个流派机制占一个机制槽；同流派后续防具被并入该机制升 Lv，不占新槽。

```text
已用机制槽数 = 单位当前觉醒的不同流派数
某流派 Lv   = 该流派吞掉的同流派防具贡献，受品质上限约束
```

建议数据字段直接改为 `mechanism_slots`；UI 文案统一为“流派槽”。

例子：2 槽单位：

```text
槽1：烈焰 Lv2（吞 2 件烈焰防具）
槽2：守护 Lv1（吞 1 件守护防具）
```

再获得烈焰防具 → 槽1 变烈焰 Lv3，仍只占 1 槽。  
再获得灰烬防具 → 已满槽，选择放弃或覆盖烈焰 / 守护。

### 4.3 单位机制槽名单

| 槽数 | 单位 | 理由 |
|---|---|---|
| 1 槽 | armored、dragonborn | 本体强，走单机制专精 |
| 2 槽 | spearman、pegasus、archer、axeman、cleric | 大部分单位，主流派 + 副流派 |
| 3 槽 | swordsman、mage | 成长多分支，靠多机制形成差异 |

### 4.4 流派计算

| 状态 | 规则 |
|---|---|
| 第一件同流派 | 觉醒完整机制，占 1 个机制槽 |
| 第 2/3/4 件同流派 | 并入同一机制升 Lv，不占新槽 |
| 品质 | 决定机制 Lv 上限：common 1 / rare 2 / epic 3 / legendary 4 |
| 不同流派 | 开新机制槽，受单位 1/2/3 槽限制 |
| 主动技能共鸣 | 若开局主动技能与某流派同标签，可给该机制一次额外加成（具体数值待配平） |
| 转职被动 | 固定不变，不参与重掷、互换或流派并入 |

六流派机制沿用 `EquipmentSlimPlan.md`：

| 流派 | 机制 |
|---|---|
| 烈焰 | 攻击附带灼烧 |
| 守护 | 格挡时反弹伤害 |
| 轮回 | 击杀回魂火 |
| 献祭 | 扣血换攻击 |
| 灰烬 | 移动后留下燃烧地块 |
| 余烬 | 魂火耗尽时下击必暴 |

### 4.5 防具领取台

每次防具 roll 产生 1 件待领取防具，玩家做一次决定：

1. **装备 / 并入**：目标无该流派 → 觉醒；已有该流派 → 升 Lv。
2. **重铸流派**：花金币换流派，品质和词条不变。
3. **合并**：仅同流派、同机制合并升层。
4. **覆盖**：满槽时选一条已有机制覆盖，二次确认。
5. **放弃**：直接丢弃。

覆盖 / 放弃不额外收费，避免二次惩罚。防具词条仍存在但出生即定、不可互换、灰显只读。

## 五、经济参数

直接复用现有 `economy_config.json`，不新造数值体系。

| 行为 | 价格 / 参数 |
|---|---|
| 单次防具 roll | 100G 起，每次 +50G；复用 `shop.base_reset_cost` + `shop.reset_step` |
| roll 会话重置 | 离开战后结算界面后重置为 100G |
| 升级 roll 品质等级 | 200 / 500 / 1200 / 2500 / 5000，复用 `shop.upgrade_costs` |
| 品质权重 | 复用 `shop.quality_weights` 6 档表 |
| 同流派合并 | 200G，复用 `forge.craft_cost` |
| 重铸流派 | 500G，复用 `forge.reforge_cost` |
| 覆盖 / 放弃 | 0G |
| 战斗金币奖励 | START 75 / NORMAL 175 / ELITE 350 / BOSS 750 |

节奏预估：普通战后约 1 次 roll，精英约 2 次，BOSS 约 3~4 次。数值先沿用，实测后再调。

## 六、遗物分类

统一数据字段：`lifetime: "persistent" | "consumable"`。

| 原光环 | 新类型 | 新行为 |
|---|---|---|
| 薪火相传 `aura_ember` | consumable | 战场使用：本场战斗每回合开始 +1 魂火，战斗结束移除 |
| 轮回流转 `aura_cycle` | consumable | 战场使用：本场战斗击杀 +1 魂火，战斗结束移除 |
| 灰烬之拥 `aura_ash` | persistent | 本局持续：受伤 -10%，反击 +30% |
| 焚身 `aura_flame` | persistent | 本局持续：全队攻击 +15% |
| 铁壁 `aura_guardian` | persistent | 本局持续：全队双减 +10% |
| 血脉燃烧 `aura_sacrifice` | persistent | 本局持续：击杀治疗 15% 最大 HP |

分类原则：**只有会直接产出魂火的才做消耗型**，其余全部持续型。原因是魂火是主动技能与流派机制的核心资源，常驻产魂火会打穿消耗决策。

局内商店不再出售光环；局外光环研究如保留，只负责解锁这些遗物。

## 七、删除与保留

### 删除 / 停用

- 地图装备界面的拖拽、词条操作、方向调整、商店、铁匠铺、单位交换位置。
- 魂栈的商店 / 铁匠铺 / 光环页签。
- 连通与箭头的玩家层操作。
- 战后结算中的防具掉落。
- 宝箱三选一中的防具选项。
- 装备界面单位升级按钮与金币费用。

### 保留

- 魂火三态、命中 +1、阵亡 +5、魂火爆发。
- 六流派身份与流派配色。
- 熔铸单位节点，作为伤亡价值化出口。
- BOSS 后遗物三选一。
- 局外魂成长、派遣、剧情、竞技场（暂不改造）。
- 伤害公式、减伤率 75% 上限、最低保底 10%。

## 八、实施顺序

1. 新建只读 Build 面板，替换 `MapScene` 的装备界面。
2. 魂栈去商店 / 铁匠 / 光环，只保留熔铸单位。
3. 做开局主动技能 roll。
4. 做战后结算 + 防具 roll + 领取台。
5. 只做烈焰一个流派作为样板，验证觉醒 / 并入 / 一键落位。
6. 铺开其余五个流派机制。
7. 竞技场对齐留到主线稳定后再做。

## 九、验收标准

| 场景 | 通过标准 |
|---|---|
| 地图装备界面 | 只能查看，所有可操作控件消失；信息按单位 → 流派机制 → 装备贡献分层 |
| 开局 roll | 只出现已选单位可装备技能；3 次不重复；落位后锁定；无重掷入口 |
| 战后结算 | 只显示金币 / 魂 / 解锁；没有防具卡片 |
| 防具 roll | 价格递增正确；可升级品质等级；领取台可装备 / 并入 / 重铸 / 覆盖 / 放弃 |
| 机制槽 | 同流派后续防具不占新槽，只升 Lv；异流派才占新槽；满槽必须选覆盖或放弃 |
| 遗物 | 只有 persistent / consumable 两类；消耗型战场使用后有明确移除反馈 |
| 单位成长 | 战后自动升级；装备界面无升级按钮 |
| 竞技场 | 本轮保持 v5 规则，不受主线改造影响 |

## 十、风险与待验证

1. 烈焰之外的五个流派机制需要逐条接入战斗层，并在后续对齐竞技场。
2. 防具 roll 的价格曲线沿用商店数据，实际节奏需试玩校准。
3. 开局技能池最小为 3，虽够 3 次 roll，但缺少重掷后运气方差更高。
4. 1 槽单位只能开一个流派，若机制升 Lv 不足，可能显得单薄。
5. 3 槽单位若前期拿到三种流派，可能强度或认知负担偏高。
6. 主动技能与流派机制的共鸣数值尚未定，建议烈焰样板时一并验证。
7. 本总结不包含代码改动；所有规则需在主玩法文档与实施清单确认后再落地。
