### 敌方威胁区红点随光标漂移（v5.10）
三张截图对比：不只是红点，棕色/红色格子整片形状也在变（像素 diff 有 73~90 个 32px 块变化）。四层根因：

3. **绘制层**：`_refresh_danger_zones` 只写数据不重绘，而 `_update_drag` 有多条提前 return 分支（悬停单位、超范围）各自用不同参数调 `show_enemy_preview`，变成"谁最后画谁说了算"。
4. **竞态**：`HighlightManager._process_incoming` 用 `queue_free` + 重建切换红点，同帧多次重绘会拿到待删除节点，红点闪烁/漏画。
修复：
- Battlefield：删 `calc_enemy_danger_zones_with_virtual`，改公开 `refresh_enemy_danger_zones()`（内部只调静态 `_calc_enemy_danger_zones`）；`_show_unit_ranges` 改走同一入口。
- DragMoveController：删 `_last_danger_virtual_cell` / `_refresh_danger_zones` 与 virtual 计算块；`_start_drag` 只算一次；新增 `_filtered_danger()` 供 `show_move_highlight` / 悬停分支 / `_redraw_highlights` 三处共用同一口径；`_find_closest_reachable_cell` 仍被 241/450 行使用，保留。
- HighlightManager：红点改 `visible` 切换，不再 queue_free/重建。
校验：3 个 .gd 括号平衡、无重复函数、无缩进混用、无旧符号残留引用。仍无 Godot 4.7 CLI，未实机验证。

### GameDataEditor 面板重叠 Bug 修复（v5.6.1）
现象：截图显示"单位"页里单位编辑/单位解锁面板叠在一起，"数值编辑"页也被单位列表面板覆盖，信息混乱；控制台报 `GameDataEditor.gd:507 @ _build_subtab_group(): Can't add child ... already has a parent`。
