## v6.72al：修 UIButtonManager 延迟调用崩溃
- 报错 `_call_function: Error calling deferred method: 'Node(UIButtonManager.gd)::_setup_button': Cannot convert argument 1 from Object to Object.`
- 根因：`call_deferred("_setup_button", node)` 把节点对象放进消息队列。按钮常在帧末前被 queue_free（弹窗关闭/卡片重建），延迟调用执行时对象已释放，Godot 在**参数类型转换阶段**（绑定到 `btn : Button`）就失败并报这条 Object→Object 的怪错，函数体内的 `is_instance_valid` 根本来不及执行。
- 修法：改用 `_queue.append(weakref(node))` + 无参 `call_deferred("_flush_queue")`，队列刷出时 `w.get_ref()` 再判 `is_instance_valid` / `is Button`，已释放的静默跳过。加了 `_flush_queued` 标志避免一帧内重复排程。
- 教训：call_deferred / 信号回调**不要把 Node 对象当参数传**，一律传 WeakRef 或 InstanceId，接收端再取引用判存活——尤其 UI 动态创建/销毁频繁的场景。这条对 Godot 4 通用。
